# KA Concept

Landing page do salão KA Concept: transformações, loiros e coloração avançada, no Parque das Nações, Lisboa.

## Antes de publicar
- **Instagram:** abra `script.js` e escreva o nome de utilizador em `INSTAGRAM` (sem @). Enquanto estiver vazio, os botões de Instagram ficam escondidos.
- **WhatsApp:** já configurado com 351967733558 (também no topo de `script.js`).
- **Serviços, tons e horário:** em `index.html`, procure ✏️.

## Publicar no GitHub Pages
1. Crie um repositório novo no GitHub (ex.: `kaconcept`).
2. Envie todos os ficheiros desta pasta, incluindo `assets/` e `.nojekyll`.
3. Em **Settings → Pages**, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)` e clique **Save**.
4. Em 1–2 minutos o site fica em `https://SEU-UTILIZADOR.github.io/kaconcept/`.

## Estrutura
```
index.html   página
style.css    estilos
script.js    WhatsApp, Instagram e seletor de tons
assets/      logótipo (fundo transparente), monograma, favicon e imagem de partilha
.nojekyll    evita processamento Jekyll
```
